Fabrication

Fabricating and manufacturing 3D printed components and all fabricated tools used on the machine, including:

  • Gripper.
  • Robotic Arm.
  • Vision systems.
  • Spacers.
  • Motors Holders.
  • Sensors Holders.

Pneumatic Circuit

  • Pneumatic vacuum circuit: compressor → filter-regulator → 3/2 solenoid valve → Venturi ejector → dual 1 in/12-out manifolds → twelve suction cups.
  • De-energized (fail-safe) state: The valve is 3/2 normally closed, so with no electrical signal the supply path is blocked, and the vacuum line is vented to atmosphere. The gripper cannot hold a load with power or signal lost and cannot accidentally energize on a control fault.

Walle (semi-humanoid)

ROS 2Raspberry Pi 4ESP32Whisper APIChatGPT API

Walle is a semi-humanoid intelligent robot powered by ROS 2, designed to interact with humans using voice commands and AI-driven decision-making. It integrates multiple actuators, including head and hand servos and wheel motors, to perform complex motions. The robot uses OpenAI's Whisper API for voice-to-text and ChatGPT API for intelligent decision making, providing real-time interactive capabilities. Raspberry Pi 4 and ROS2, ESP32, and Mechanical Design are attached.

Red Dot Shooter

ROS 2PythonC++PIDStepper motors

This project integrates robot vision with motor control in ROS 2 for real-time object tracking. A modular set of nodes detects a red object, computes its coordinates, applies inverse kinematics, and uses a PID controller to drive stepper motors. Designed for scalability and industrial use, it supports both Python and C++.

Embedded & Software

PID Autonomous Car

Arduino UnoPIDMATLABProteus

Microcontroller: Arduino Uno. Controller: PID Control. Application: searching for a specific object and finding it. Input: distance from an ultrasonic sensor controlled by a servo motor. Output: velocity of the vehicle, adjusted based on the distance from the ultrasonic sensor and DC motors, which are controlled by a motor driver L298N. We utilized MATLAB for time-frequency responses and Proteus for simulating the process. A big thank you to everyone who supported and guided me throughout this project!
